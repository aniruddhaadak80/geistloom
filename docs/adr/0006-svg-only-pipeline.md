# ADR-0006: SVG-only image pipeline (gen-assets.mjs)

- Status: Accepted
- Date: 2026-10-11

## Context

The frame needs many images: favicon, apple-touch-icon, logo, hero banner, og card, six product screen mockups, and the architecture poster. Raster assets blur on hi-dpi screens, bloat the repo, cannot be diffed meaningfully in review, and require designer tooling to change.

## Decision

Every image is an SVG generated by `scripts/gen-assets.mjs` — zero dependencies (node:fs only), deterministic geometry from the seeded `mulberry32` PRNG, the palette object shared with the Tailwind tokens. The generated SVGs are committed alongside the script; regeneration is byte-identical.

## Consequences

- Infinite resolution at a few KB per surface; the six screen mockups cost less than one screenshot.
- Assets are reviewable: a design change is a diff of geometry, not a binary blob.
- No designer tooling required to restyle — the palette and layout constants are code.
- Animation is declarative SVG `<animate>` only (pulsing LIVE dot, blinking cursor); no JavaScript, no randomness.
- CI re-runs the generator and diffs the output; a dirty tree means someone hand-edited a generated file.
- Photographic content is permanently out of scope — acceptable, because the frame's surfaces are dashboards, charts, and diagrams.
